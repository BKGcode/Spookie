# FPS Controller - Nuevas Funcionalidades

## ✅ Funcionalidades Implementadas

### 🏃‍♂️ **Movimiento**
- **WASD/Arrow Keys**: Movimiento básico
- **Shift**: Correr (velocidad aumentada)
- **C**: Agacharse (velocidad reducida, altura disminuida)

### 🎯 **Cámara**
- **Mouse**: Control de vista
- **Sensibilidad ajustable**: En PlayerSettingsSO
- **Sensibilidad reducida al agacharse**: Para mayor precisión

### ⬆️ **Salto**
- **Space**: Saltar
- **Altura configurable**: En PlayerSettingsSO
- **Gravedad realista**: Física mejorada

### 🎮 **Interacción**
- **E**: Interactuar con objetos
- **Rango configurable**: En PlayerSettingsSO

### 🖱️ **Cursor**
- **Tab**: Alternar visibilidad del cursor

## ⚙️ **Configuración en PlayerSettingsSO**

### Movement Settings
- `Walk Speed`: Velocidad de caminata (default: 5)
- `Run Speed`: Velocidad de carrera (default: 8)
- `Crouch Speed`: Velocidad agachado (default: 2.5)
- `Jump Height`: Altura del salto (default: 2)
- `Gravity`: Gravedad (default: -9.81)

### Mouse Look Settings
- `Mouse Sensitivity`: Sensibilidad del mouse (default: 2)
- `Crouch Mouse Sensitivity`: Sensibilidad agachado (default: 1)
- `Max Look Angle`: Ángulo máximo de vista (default: 80)

## 🎯 **Controles**

| Acción | Tecla | Descripción |
|--------|-------|-------------|
| Movimiento | WASD/Arrow Keys | Movimiento básico |
| Correr | Shift | Aumenta velocidad |
| Agacharse | C | Reduce altura y velocidad |
| Saltar | Space | Salto vertical |
| Interactuar | E | Interactuar con objetos |
| Cursor | Tab | Alternar visibilidad |

## 🔧 **Configuración Rápida**

1. **Abrir PlayerSettingsSO** en `Assets/PlayerSettings.asset`
2. **Ajustar valores** según tus preferencias
3. **Probar en Play Mode**

## 🎮 **Consejos de Uso**

- **Agacharse** es útil para pasar por espacios pequeños
- **Correr** consume más "energía" (para futuras implementaciones)
- **Sensibilidad de cámara** se reduce al agacharse para mayor precisión
- **Salto** solo funciona cuando estás en el suelo
